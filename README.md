\# Nauta Explora 🛶



Nauta Explora is a web platform that connects tourists with local businesses

in Nauta, Peru — the gateway to the Pacaya Samiria National Reserve.



\## The Problem



Tourists arriving from Iquitos struggle to find reliable information about

tours, guides, lodging, and river transport.



\## The Solution



This platform offers a verified business directory, practical travel guides,

and direct WhatsApp contact with each business.



\## Tech Stack



Built with HTML, CSS, and JavaScript.

Migration to React, TypeScript, Node.js, and PostgreSQL is planned

as the project evolves.



\## Status



🚧 In active development. First public version expected in 2026.
